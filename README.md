# Quantum Anchor — Playable Web-Builds

Privates Repo für schnelle Web-Build-Freigaben an Paul während der Entwicklung von
[Quantum Anchor](https://github.com/MarkusUngerDev/quantum-anchor-game). Kein Quellcode — nur
der jeweils aktuelle Godot-Web-Export (`index.html` + zugehörige Dateien), gehostet über
GitHub Pages.

Aktualisiert wird per `godot --headless --export-release "Web" ...` aus dem Hauptrepo, siehe
dort `publish_web_build.sh`.
